# Monitoria de Teoria dos Grafos e Computabilidade

Este repositório reúne o material de apoio da **monitoria da disciplina de Teoria dos Grafos e Computabilidade**. O objetivo é centralizar, em um único lugar de fácil acesso, os _slides das aulas_, as _referências utilizadas_ e os _conteúdos complementares_ trabalhados ao longo do semestre, para que os alunos possam revisar os tópicos no próprio ritmo, se preparar para provas e trabalhos e acompanhar as aulas gravadas com o material em mãos. Todo o conteúdo está organizado na ordem em que os assuntos são apresentados na disciplina, cobrindo desde os _conceitos fundamentais de grafos_ até os _algoritmos clássicos_ de caminho mínimo, fluxo máximo, emparelhamento, coloração e planaridade.

## 📝 Sobre o Projeto

Este repositório nasceu do trabalho de **monitoria da disciplina de Teoria dos Grafos e Computabilidade** e existe para auxiliar os alunos que estão cursando a matéria.

- **Por que ele existe:** durante o semestre, o material da disciplina costuma ficar espalhado entre plataformas, mensagens e arquivos avulsos. Aqui, tudo fica versionado, organizado e disponível a qualquer momento.
- **Qual problema ele resolve:** dá aos alunos um ponto único de consulta para os slides das aulas, na ordem correta do conteúdo, facilitando a revisão de tópicos específicos antes de provas, listas de exercícios e trabalhos.
- **Qual o contexto:** acadêmico, voltado ao curso de Engenharia de Software e às turmas da disciplina de Teoria dos Grafos e Computabilidade.
- **Onde ele pode ser utilizado:** no estudo individual, no acompanhamento das aulas gravadas, nas sessões de monitoria e na preparação para avaliações.

> [!NOTE]
> O material aqui disponibilizado é **complementar** às aulas. Ele não substitui a presença nas aulas, a bibliografia oficial da disciplina nem as orientações do professor responsável pela turma.

## ✨ O que você encontra aqui

- 📑 **Slides das aulas:** todos os tópicos da disciplina em PDF, numerados na ordem em que são apresentados.
- 🧭 **Organização por tema:** da introdução aos grafos até algoritmos avançados de fluxo, emparelhamento e coloração.
- 🎥 **Apoio às aulas gravadas:** os slides usados nas aulas gravadas ficam disponíveis para consulta durante e depois da gravação.
- 🧮 **Cobertura dos algoritmos clássicos:** DFS, BFS, Kosaraju, Fleury, Prim, Kruskal, Dijkstra, Bellman-Ford, Floyd-Warshall, Ford-Fulkerson, Edmonds-Karp, Dinic, Kahn, Edmonds e Welsh-Powell.
- 🔗 **Referências de estudo:** indicações de livros, documentações e ferramentas de visualização para aprofundamento.

## 🔧 Como Utilizar

Não é necessário instalar nada para consultar o material. Existem duas formas principais de acesso:

### 🌐 Direto pelo GitHub

Navegue até a pasta [`slides/`](./slides) e clique no arquivo desejado. O GitHub exibe a pré-visualização dos PDFs no próprio navegador, e o download pode ser feito pelo botão de download da página do arquivo.

### 💻 Clonando o repositório

Para manter uma cópia local de todo o material:

```bash
# Clone o repositório
git clone https://github.com/arturbomtempo-dev/graph-theory-monitoring.git

# Acesse a pasta do projeto
cd graph-theory-monitoring

# Liste os slides disponíveis
ls slides
```

Para atualizar sua cópia local sempre que novos materiais forem adicionados:

```bash
git pull origin main
```

> [!TIP]
> Se você só quer um arquivo específico, use a opção **Download** disponível na página do repositório no GitHub para baixar o conteúdo completo em `.zip` ou apenas o PDF desejado.

## 🔗 Documentações e Referências

Materiais recomendados para aprofundar os tópicos abordados na disciplina:

- 📖 **Livro base:** BONDY, J. A.; MURTY, U. S. R. [**Graph Theory with Applications**](https://www.zib.de/groetschel/teaching/WS1314/BondyMurtyGTWA.pdf)
- 📖 **Algoritmos (edição original):** CORMEN, T. H. et al. [**Introduction to Algorithms (CLRS)**](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/). 4. ed. Cambridge: MIT Press, 2022.
- 📖 **Teoria dos grafos avançada:** DIESTEL, R. [**Graph Theory**](https://diestel-graph-theory.com/)
- 📖 **Computabilidade:** SIPSER, M. [**Introduction to the Theory of Computation**](https://math.mit.edu/~sipser/book.html)
- 🧪 **Visualização de algoritmos:** [**VisuAlgo**](https://visualgo.net/en/graphds) e [**Graph Online**](https://graphonline.top/en/)
- 🐍 **Biblioteca para experimentação:** [**Documentação do NetworkX**](https://networkx.org/documentation/stable/)
- 📚 **Exercícios e explicações complementares:** [**GeeksforGeeks: Graph Data Structure and Algorithms**](https://www.geeksforgeeks.org/graph-data-structure-and-algorithms/)

## 🤝 Contribuição

Sugestões de melhoria, correções e novos materiais de apoio são muito bem-vindos, especialmente vindos dos próprios alunos da disciplina.

1. Faça um `fork` do projeto no GitHub.
2. Crie uma branch para sua contribuição (`git checkout -b feature/minha-contribuicao`).
3. Faça o commit das suas mudanças (`git commit -m 'docs: adiciona material de apoio sobre X'`). **(Utilize [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/))**
4. Envie a branch para o seu fork (`git push origin feature/minha-contribuicao`).
5. Abra um **Pull Request (PR)** para a branch `main` deste repositório.

> [!IMPORTANT]
> 📝 Encontrou um erro em algum slide ou sentiu falta de algum conteúdo? Abra uma **issue** no GitHub descrevendo o ponto. Materiais de terceiros só podem ser adicionados com a devida autorização e o crédito ao autor original.
